# Bienvenido a la Guía de Desarrollo Web

![Banner del proyecto](img/banner.png)

Esta documentación cubre los fundamentos del desarrollo web moderno, desde HTML básico hasta JavaScript interactivo.

## ¿Qué aprenderás?

- Estructura de páginas con **HTML**
- Diseño y estilos con **CSS**
- Interactividad con **JavaScript**

## Secciones

| Sección | Descripción | Dificultad |
|---------|-------------|------------|
| [HTML](html.md) | Estructura y etiquetas básicas | Principiante |
| [CSS](css.md) | Estilos, colores y diseño responsivo | Intermedio |
| [JavaScript](javascript.md) | Lógica, eventos y manipulación del DOM | Intermedio |

!!! tip "Consejo para empezar"
    Si eres nuevo en desarrollo web, comienza por la sección de [HTML](html.md) antes de pasar a CSS y JavaScript.

## Requisitos previos

- Un editor de texto (VS Code, Sublime Text, etc.)
- Un navegador web moderno (Chrome, Firefox, Edge)
- Ganas de aprender 🚀
